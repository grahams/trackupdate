# Live TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `./trackupdate.py -e <n>` open a Textual TUI attached to a separate, crash-isolated engine process that logs tracks live (SQLite + NowPlaying.txt only) and generates all file artifacts from the db at end of show.

**Architecture:** A pure `Session` state machine decides what to dispatch from each Swinsian poll (overrides, stop values, intro wait, dedupe). An `Engine` owns the session, the live plugins and a db connection, and processes poll ticks and client commands serially on one thread; a Unix-socket server relays newline-delimited JSON between the engine and any attached TUI. The TUI is a thin Textual client that renders engine snapshots and sends commands; it holds no state of its own.

**Tech Stack:** Python 3.13 (conda base at `/opt/homebrew/Caskroom/miniconda/base`), Textual, pytest, sqlite3, stdlib `socketserver`/`asyncio`.

**Spec:** `docs/superpowers/specs/2026-10-21-live-tui-design.md`

## Global Constraints

- Work only in the worktree `~/src/trackupdate/.worktrees/live-tui` on branch `feature/live-tui`. `main` must stay runnable for live shows; never commit to it.
- Plugin filename == class name == config section; `[SqliteTarget].dbPath` is the canonical db path.
- Quote `"ignore"` in all SQL. New rows use space-separated `startTime` (`YYYY-MM-DD HH:MM:SS.ffffff`).
- Only plugins with `enableArchive = False` run live. Plugins with `enableArchive = True` are **constructed** only at end of show (their `__init__` opens output files with `'w'`).
- `SqliteTarget` can never be toggled off.
- Override `uniqueId` is `str(uuid.uuid4())`.
- Plugin toggles are session-only; never write `~/.trackupdaterc`.
- `-a` archive mode behaviour and output are unchanged.
- The grabber path must be absolute (`<repo>/util/swinsian-track-grabber`), since the engine is spawned detached.
- New dependencies: `textual` (runtime), `pytest` (dev). Add both to `environment.yml`.
- Runtime files live in `~/.trackupdate/` (override with env `TRACKUPDATE_RUNTIME_DIR`): `engine.sock`, `engine.json`, `override.json`, `engine.log`.

## Review Focus

1. **Engine restart while a corrected track is playing.** The user fixed a typo in the current row; the engine restarts; Swinsian still reports the raw (typo'd) title. Expected: no duplicate row (dedupe by `uniqueId` first). Test in Task 3.
2. **Grabber failure (timeout/bad JSON) during an override.** Expected: treated as "no information", never as "Swinsian stopped" or "Swinsian resumed". Test in Task 3.
3. **Restart mid-override with Swinsian paused, then Swinsian resumes.** Expected: override restored, no row logged at startup, exactly one row when Swinsian resumes. Test in Task 6.
4. **A file plugin raising in `__init__`, `logTrack` or `close` at end of show.** Expected: the remaining plugins still run, the summary names the failure, the engine still exits and removes its runtime files. Test in Task 6.
5. **TUI started before the engine socket is up, or engine dies while attached.** Expected: TUI shows "disconnected — retrying" and reconnects; it never raises. Test in Task 9.

### Task 3: Session state machine

**Files:**
- Create: `session.py`, `tests/test_session.py`

**Interfaces:**
- Consumes: `Track` (`Track.py`).
- Produces:
  ```python
  @dataclass
  class OverrideState:
      track: Track
      swinsian_idle: bool   # True once Swinsian has reported {} since the override was set

  class Session:
      def __init__(self, *, ignore_album: str | None, intro_album: str,
                   stop_track: Track | None, current: Track | None = None,
                   override: OverrideState | None = None, started: bool = False,
                   last_report: dict | None = None): ...
      current: Track | None
      source: str | None          # "swinsian" | "override" | "stop"
      override: OverrideState | None
      last_report: dict | None
      def on_poll(self, report: dict | None) -> Track | None
      def set_override(self, title: str, artist: str, album: str, length: str) -> Track
      def cancel_override(self) -> None
  ```
  `on_poll` returns a Track to dispatch (with `artworkURL=None`; the engine fills artwork) or `None`. `stop_track` is `None` when `useStopValues` is not `'True'`.

**Rules (the algorithm the tests pin):**
1. `report is None` → return `None`; change nothing.
2. Not `started`: if `report == {}` or (`intro_album` and `report.get("trackAlbum") == intro_album`) → record `last_report`, return `None`. Otherwise set `started = True` and continue.
3. Override active:
   - `report == {}` → `override.swinsian_idle = True`; record; return `None`.
   - `report` non-empty and `swinsian_idle` → clear override, then handle as a new Swinsian track, **skipping the `last_report` equality check** (resuming the same paused track still logs).
   - `report` non-empty and not idle → record; return `None` (muted playlist advance is ignored).
4. Normal: `report == last_report` → `None`. Record. `{}` → `stop_track` copy (source `"stop"`) or `None`. Else build a Track from `trackName/trackArtist/trackAlbum/trackLength/trackId` (missing keys → `""`), source `"swinsian"`.
5. Dedupe against `current`: same non-empty `uniqueId` → `None`; else same `(artist, title)` → `None`.
6. Set `ignore = (album == ignore_album)`, set `current`, `source`; return the track.
- `set_override`: `uniqueId = str(uuid.uuid4())`, `ignore` per rule 6, `override = OverrideState(track, swinsian_idle=last_report in (None, {}))`, `current = track`, `source = "override"`, `started = True`; returns the track.
- `cancel_override`: `override = None`; nothing else (the next *change* from Swinsian is followed).

### Task 6: Engine core (no sockets)

**Files:**
- Create: `engine.py`, `tests/test_engine.py`

**Interfaces:**
- Consumes: Tasks 1–5.
- Produces:
  ```python
  class Engine:
      def __init__(self, *, config, episode: str, plugin_classes: list[type],
                   poller=track_source.poll_swinsian,
                   artwork=track_source.search_artwork,
                   connect=lambda: sqlite3.connect(db_path), now=datetime.now): ...
      def start(self) -> None          # build Session (resume), construct LIVE plugins only
      def tick(self) -> None           # one poll → maybe dispatch
      def handle(self, cmd: dict) -> None
      def snapshot(self) -> dict
      def end_show(self) -> list[dict]
      def subscribe(self, fn: Callable[[dict], None]) -> None   # called with every snapshot/event
      def submit(self, cmd: dict) -> None   # thread-safe enqueue
      def run(self, poll_time: float) -> None   # loop: queue.get(timeout) → handle; on timeout → tick; returns after end_show
  ```
- Snapshot (sent after every state change, and on `hello`):
  ```json
  {"event": "snapshot", "episode": "412", "phase": "live|ending|ended",
   "onAirSince": "2026-10-21 20:00:12.000000" | null,
   "nowPlaying": {"title","artist","album","length","source"} | null,
   "overrideActive": false, "currentRowid": 18 | null,
   "tracks": [ list_rows(...) ],
   "plugins": [{"name": "CueFileTarget", "kind": "live|file", "enabled": true, "locked": false}],
   "lastError": null, "results": []}
  ```
- Commands: `{"cmd":"hello"}`, `{"cmd":"edit_row","rowid","title","artist","album"}`, `{"cmd":"toggle_ignore","rowid"}`, `{"cmd":"set_override","title","artist","album","length"}`, `{"cmd":"cancel_override"}`, `{"cmd":"toggle_plugin","name"}`, `{"cmd":"end_show"}`. An invalid command sets `lastError` and emits a snapshot; it never raises.

**Behaviour:**
- `start`: resume from the db. `current = row_to_track(last_row)` and `started = True` when rows exist. `load_override()` is applied only if its track's `uniqueId` equals `last_row["uniqueId"]`, otherwise cleared. Write `engine.json`.
- Dispatch: fill `artworkURL` for `swinsian`/`override` sources via `artwork(title, artist)`, falling back to `f"{coverImageBaseURL}/{stopArtwork}"` (same default as today, including the `YYYYMMDD.jpg` fallback for empty `stopArtwork`). Call `logTrack(track, now())` on enabled live plugins in priority order, each in its own try/except (log the error and set `lastError`). Then `currentRowid = last_row(...)["rowid"]`. Persist or clear `override.json` whenever `session.override` changes.
- A `None` poll result sets `lastError = "Swinsian poll failed (see engine.log)"`; the next successful poll clears it.
- `edit_row` on `currentRowid` also updates `session.current` and re-sends the corrected track to every enabled live plugin **except** `SqliteTarget`.
- `toggle_plugin`: refuses `SqliteTarget` (`lastError`). Re-enabling a live plugin sends it `session.current` immediately.
- `end_show`: phase `ending` → snapshot → `close()` live plugins (isolated) → `archive.generate` with enabled file plugins → phase `ended`, `results` → snapshot → `clear_runtime()`.
- The engine's own `sqlite3` connection and all plugin instances are created and used **only on the thread that calls `run`** (SQLite connections are thread-bound).
